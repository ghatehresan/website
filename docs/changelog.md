# تغییرات مخزن سایت

## پیش‌نمایش دیداری — ۲۰۲۶-۰۹-۲۴

- صفحهٔ مفهومی و قابل کلیک فارسی/RTL در `prototype/` با رنگ/نماد رسمی برند، فونت self-host دارای SIL OFL و تصویر مفهومیِ برچسب‌خوردهٔ بستهٔ برند افزوده شد.
- جست‌وجو و انتخاب خودرو فقط حالت خالیِ صادقانه دارند؛ نقشهٔ راه و چک‌لیستِ محلی کارفرما اضافه شد. دادهٔ کاربر به سرور یا سایت واقعی ارسال نمی‌شود؛ هیچ محصول/قیمت/خودروی ساختگی نیست.
- سرور ایزولهٔ Python برای پیش‌نمایش با هدر noindex فراهم شد؛ WordPress/Production، درگاه، URLها و دیتابیس تغییر نکردند. تعامل‌ها در مرورگر headless، عرض‌های ۳۲۰ تا ۱۴۴۰ و اسکن خودکار WCAG A/AA بدون یافتهٔ خودکار تست شدند؛ هنوز نیازمند QA انسانی است. تبدیل این طرح به child theme/plugin مشروط به Staging، بکاپ و دادهٔ واقعی است.

## بازبینی عمومی پس از پاک‌سازی مالک — ۲۰۲۶-۰۹-۲۴

- بنا بر اعلام مالک، محصولات، نوشته‌ها و دسته‌های demo از سایت حذف شده‌اند. بررسی عمومیِ فقط‌خواندنی نشان داد اکنون API محصول و نوشته خالی است، اما یک دستهٔ محصول و ۹ دستهٔ نوشتهٔ خالی باقی مانده‌اند؛ API ویژگی‌های محصول نیز خالی شده است.
- `/blog/` عادی هنوز کارت‌های نوشته‌های سابق را نشان می‌دهد در حالی که نسخهٔ دارای query تازه/REST خالی است؛ خانه، تماس و سیاست بازگشت نیز هنوز متن/تصویر demo دارند. گزارش و نقشهٔ URL با تمایز **عکس تاریخی** از وضعیت تازه به‌روزرسانی شدند.
- حذف محتوا توسط مالک انجام شده است، نه این مخزن/عامل. وضعیت بکاپ، HTTP status، سفارش‌های قبلی و کش از پنل تأیید نشده و هیچ تغییری روی Production از طرف ما انجام نشده است.

## مرحلهٔ ۱ — ۲۰۲۶-۰۹-۲۴

- ممیزی فقط‌خواندنی سایت عمومی، ZIP مخزن برند، ZIP مخزن سامانهٔ مدیریت و سند فروشندهٔ WoodMart ثبت شد.
- گزارش A–T و اسناد تصمیم معماری/طراحی/Taxonomy/خودرو/برند/Woo/SEO/ریدایرکت/ادغام/امنیت/عملکرد/استقرار تهیه شد.
- **هیچ تغییر Production، بکاپ واقعی، نصب وردپرس، import محصول، کد plugin/theme، تغییر URL یا آزمایش پرداخت انجام نشده است.**
- گام بعدی مشروط به دسترسی امن Staging، بکاپ قابل بازیابی، کاتالوگ و fitment واقعی و تصویب مالک کسب‌وکار است.
