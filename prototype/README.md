# پیش‌نمایش مفهومی قطعه‌رسان · قدم اول

این پروژه یک **نمونهٔ دیداری و قابل کلیک، کاملاً جدا از سایت زنده** است؛ WordPress/قالب WoodMart را تغییر نمی‌دهد. هیچ API، محصول، خودرو، قیمت، سازگاری، checkout، حساب کاربری یا تحلیل‌گر متصل نیست. جست‌وجو فقط حالت خالیِ صادقانه نشان می‌دهد و چک‌لیست اختیاری فقط در `localStorage` مرورگر خود بازدیدکننده نگهداری می‌شود. هیچ فرم انتقال داده‌ای ندارد. با `noindex` و `X-Robots-Tag` از ایندکس‌شدن پیش‌نمایش جلوگیری شده است. **این فایل‌ها آمادهٔ نصب روی Production نیستند.**

## اجرا

از ریشهٔ مخزن، بدون نصب وابستگی:

```sh
python3 prototype/serve.py
```

پورت پیش‌فرض `4173` است؛ برای تغییر، متغیر محیطی `PORT` تنظیم شود. سرور برای پیش‌نمایش به `0.0.0.0` bind می‌شود، نه برای ارائهٔ امن عمومی در هاست واقعی. اگر از یک سرور HTTP دیگر استفاده می‌کنید، هدر `X-Robots-Tag: noindex, nofollow` را نیز اعمال کنید.

## محدوده و منبع دارایی‌ها

- `assets/mark-navy.png`, `assets/mark-white.png`, `assets/favicon-32.png` از [بستهٔ رسمی برند قطعه‌رسان، commit `fe9d144`](https://github.com/ghatehresan/brand-ghatehresan) کپی شده‌اند. لوگوتایپ HTML با Vazirmatn برای نمونه‌سازی است؛ پیش از Production نسخهٔ نهایی بدون وابستگی به فونت بیرونی/outline‌شده با تأیید صاحب برند جایگزین شود.
- `assets/brand-mood-hero.jpg` از تصویر **مفهومی AI** موجود در `brand-ghatehresan.zip/mood/hero.jpg` همان مرجع است؛ با برچسب آشکار استفاده شده و **عکس محصول، موجودی یا انبار واقعی نیست**. برای فروشگاه نهایی فقط تصاویر حقیقی و دارای حق استفاده به کار رود.
- `assets/fonts/Vazirmatn-*.woff2` از فایل فونت همراه بستهٔ [سامانهٔ مدیریت، commit `75b1a46`](https://github.com/ghatehresan/ghatehresan-management-system) کپی شده‌اند؛ مجوز SIL OFL 1.1 در `assets/fonts/OFL.txt` همراه فایل‌ها نگهداری می‌شود. هیچ درخواست به Google Fonts ارسال نمی‌شود.
- رنگ و لحن بر اساس [سند برند و ممیزی طراحی](../docs/design-system.md) است. نارنجی روی سفید به‌عنوان متن ریز استفاده نشده؛ کنتراست/کیبورد/موبایل باید هنگام تبدیل به WordPress دوباره تست شوند.

## راستی‌آزمایی این نسخه

تعامل تب‌ها، جست‌وجوی بدون ارسال شبکه، منوی موبایل و چک‌لیست با مرورگر headless آزمایش شدند. در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل سرریز افقی دیده نشد؛ اجرای خودکار axe با معیارهای WCAG 2/2.1 A/AA روی دسکتاپ و موبایل مورد نقضی گزارش نکرد. این آزمون خودکار **جایگزین بررسی انسانی، تست دستگاه واقعی یا QA ووکامرس نیست**؛ فروشگاه اصلی هنوز پیاده‌سازی نشده است.

## قدم بعد بعد از دیدن پیش‌نمایش

1. کارفرما: دربارهٔ هدر، تصویر مفهومی، لحن، مسیر جست‌وجو و صفحهٔ موبایل بازخورد مشخص بدهد. در صورت رد تصویر مفهومی، بدون جایگزینی با عکس ساختگی از طرح حذف می‌شود.
2. کارفرما/هاست: بکاپ قابل بازیابی و Staging محافظت‌شده را آماده و سفارش‌های احتمالی پیش از حذف demo و کش `/blog/` را بررسی کنند؛ credential/DB/کلید را در گفتگو یا Git نگذارند.
3. مسئول کالا: چند SKU **واقعی** با کد، برند، دسته، سال/موتور/تیپ خودرو و شاهد سازگاری، قیمت/وضعیت تأمین/عکس دارای حق استفاده ارائه دهد. نمونه‌های ZIPهای مرجع یا نام خودرو/قطعهٔ حدسی قابل استفاده نیستند.
4. پس از تأیید: معماری [گزارش A–T](../docs/phase-1-audit.md) را روی Staging پیاده کنیم؛ منطق مستقل از قالب در plugin اختصاصی، نما در child theme، بدون تغییر فایل‌های WoodMart والد. تغییر URL، پرداخت و ادغام مدیریت گیت‌های جدا دارند.
